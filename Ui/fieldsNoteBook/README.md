# Field Notebook

Field Notebook helps construction crews report blockers, track progress, and access site documents. It reduces manual reporting and keeps teams informed about issues delaying work. The web UI uses Microsoft Cognitive Services, while iOS uses Apple’s LLM to turn spoken reports into structured blocker details.

See the [project README](../../README.md) for features, architecture, speech reporting, and setup instructions for the web application, API, and iPad app.
